# יותר רעות – מועדון ההטבות הקהילתי

אפליקציית ווב (PWA) בעברית ובכיוון RTL, מותאמת קודם כול לטלפון:

- **אתר לחברות הקהילה** – חיפוש, קטגוריות, סינון (קטגוריה, עיר, אונליין/בעסק, גובה הנחה), כרטיסי הטבה, עמוד הטבה עם העתקת קופון, מימוש, שיתוף בוואטסאפ, דיווח ומועדפים. התאמות נגישות (הגדלת טקסט, ניגודיות, הדגשת קישורים, ביטול אנימציות).
- **דשבורד ניהול מאובטח** – סקירה, ניהול הטבות (כולל עריכה מרוכזת, שכפול, ארכיון, חידוש, סדר הצגה, תצוגה מקדימה), מאגר עסקים עם זיהוי כפילויות, תור אישור להטבות מהמייל, הדגמת קליטה ממייל, התראות ודיווחים, נתונים, משתמשים והרשאות, יומן פעילות, גיבוי, ייבוא/ייצוא Excel ו־CSV.

## הרצה מקומית

דרוש Node.js 22 ומעלה.

```bash
npm install
ADMIN_EMAIL=you@example.org ADMIN_PASSWORD='סיסמה-חזקה' npm start
# http://localhost:3000  ·  כניסה לניהול: #/login
```

בהרצה הראשונה נוצר קובץ הנתונים `data/db.json` עם 24 ההטבות הקיימות. אם לא הוגדרה `ADMIN_PASSWORD`, נוצרת סיסמה זמנית ומודפסת למסוף פעם אחת.

| משתנה | תפקיד |
|---|---|
| `PORT` | פורט (ברירת מחדל 3000) |
| `APP_URL` | הכתובת הציבורית, למשל `https://hatavot.reut.org.il` (נדרש ל־OAuth ולעוגייה מאובטחת) |
| `DATA_DIR` | תיקיית הנתונים והגיבויים (ברירת מחדל `./data`) |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | חשבון המנהלת הראשון |
| `ANTHROPIC_API_KEY` | מפעיל חילוץ פרטים וניסוח שיווקי בעזרת Claude. בלעדיו פועל מנוע חילוץ מקומי |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | חיבור Gmail ב־OAuth |

## חיבור Gmail (OAuth, בלי סיסמה)

1. ב־[Google Cloud Console](https://console.cloud.google.com/) יוצרים פרויקט ומפעילים את **Gmail API**.
2. במסך ההסכמה (OAuth consent screen) מוסיפים את ההרשאה `https://www.googleapis.com/auth/gmail.modify` ואת תיבת המועדון כמשתמשת בדיקה.
3. יוצרים **OAuth client ID** מסוג Web application, עם Redirect URI: `APP_URL/auth/google/callback`.
4. מגדירים בשרת את `GOOGLE_CLIENT_ID` ו־`GOOGLE_CLIENT_SECRET`, ובדשבורד: הגדרות ← Gmail ושולחים ← „חיבור עם Google”.

המערכת קוראת רק הודעות עם התווית „הטבות יותר רעות”, משולחים מאושרים, שהועברו לכתובת ההטבות או עם מילות המפתח, מהשבועיים האחרונים. כל הודעה שטופלה מקבלת את התווית „יותר רעות/טופל” ולא מעובדת שוב. ה־token נשמר בקובץ נפרד (`data/gmail-token.json`, הרשאות 600) ולא נכנס לגיבוי שמורד מהדשבורד.

**שום הטבה ממייל לא מתפרסמת בלי אישור**, אלא משולח שהמנהלת סימנה במפורש כ„מאושר” עם „פרסום אוטומטי”, וגם אז רק כשהזיהוי מלא (ציון ביטחון 70% ומעלה) וללא כפילויות.

## גרסת ההדגמה

`npm run build:demo` בונה את `dist/demo.html`: כל האפליקציה בקובץ אחד, כשהליבה רצה בדפדפן ונשמרת ב־localStorage. חשבונות ההדגמה (רק בגרסה הזו):

| תפקיד | מייל | סיסמה |
|---|---|---|

| עורכת תוכן | editor@yoter-reut.org.il | Edit2026! |
| חברת קהילה | member@yoter-reut.org.il | Member2026! |

## מבנה הקוד

```
shared/core.js     כל נתיבי ה־API, הרשאות, זרימת המייל, אוטומציות וסטטיסטיקות (רץ בשרת ובדפדפן)
shared/extract.js  סינון מיילים, חילוץ מבוסס כללים, זיהוי כפילויות
shared/seed.js     נתוני הפתיחה (24 ההטבות), מיילים לדוגמה
lib/ai.js          חילוץ וניסוח בעזרת Claude (structured outputs)
lib/gmail.js       OAuth ו־Gmail API
server.js          שרת HTTP, עוגיות סשן, CSRF, הגבלת ניסיונות כניסה, גיבוי יומי, משימות מתוזמנות
public/            ה־PWA (index.html, app/*.js, styles.css, sw.js, manifest)
demo/              ה־backend המקומי של גרסת ההדגמה
test/              בדיקות (npm test)
```

### מודל הנתונים
`users`, `businesses`, `benefits`, `categories`, `favorites`, `events` (צפייה/מימוש/העתקה/שיתוף/דיווח, בלי מידע אישי), `searches`, `reports`, `emails` (מיילים שנקלטו), `senders` (שולחים מאושרים), `alerts`, `auditLog`, `settings`. לכל רשומה מזהה ייחודי (UUID). הנתונים נשמרים בקובץ JSON עם כתיבה אטומית וגיבוי יומי ל־30 יום. כשהמאגר יגדל, אפשר להחליף את ה־store ב־`server.js` ב־PostgreSQL בלי לשנות את הליבה.

### אבטחה
סיסמאות ב־scrypt, עוגיית סשן HttpOnly/SameSite (Secure ב־HTTPS), כותרת CSRF לכל בקשה משנה, הגבלת ניסיונות כניסה, CSP, הפרדה מלאה בין נתונים ציבוריים לפנימיים (הערות, סטטוסים, מיילים ויומן לא יוצאים מה־API הציבורי), יומן פעילות לכל הוספה/עריכה/אישור/מחיקה, מחיקה סופית רק למנהלת ועם אישור מוקלד.

### מה עוד לא מחובר
- **התראות במייל/וואטסאפ** נרשמות ל־`data/notifications.log`. כדי לשלוח בפועל צריך ספק מייל (למשל SMTP) ובהמשך WhatsApp Business API.
- **מדיניות הפרטיות, תנאי השימוש והצהרת הנגישות** הן טיוטות שכדאי להעביר לבדיקה משפטית.
